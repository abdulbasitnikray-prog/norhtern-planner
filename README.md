## What it does
A traveller based in Islamabad enters trip details (dates, days, people, budget), filters 8 sample northern destinations, builds an itinerary, and gets instant cost, days-needed, season, altitude and budget-conflict checks. Runs fully in the browser; no backend.

## Run it
1. Download or clone the repo.
2. Open `index.html` in any modern browser (double-click). No install or build needed.
3. Optional: `python -m http.server 8000`, then visit http://localhost:8000
